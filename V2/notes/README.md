# V2/notes — 프로젝트 메모리 스냅샷

이 디렉터리는 Claude 데스크톱 앱의 **프로젝트 메모리**를 저장소 안에 그대로 떠 둔 것이다.

프로젝트 메모리는 원래 작업하던 컴퓨터 안에만 저장된다. 기기를 옮기거나
앱을 다시 깔면 사라지므로, git이 옮겨 줄 수 있는 자리에 사본을 둔다.

- `MEMORY.md` — 색인 (프로젝트 메모리의 MEMORY.md와 동일)
- `llm-router-*.md` — 토픽 파일 6개. 원본 그대로이며 편집하지 않는다.

파일 앞머리의 YAML frontmatter(`name` / `description` / `type`)는 프로젝트 메모리
형식이다. 다른 컴퓨터에서 되살릴 때는 이 파일들을 그대로 프로젝트 메모리에
써 넣으면 된다.

떠 둔 시점: 2026-08-30
